# CPU campaign design and deviations from the initial resource proposal

The H100 proposal was withdrawn. All computation uses the existing GCP CPU instance, with no new VM and no shutdown of the shared machine. The host has 32 cores; the study is restricted to two CPU affinities and one numerical-library thread per process. No new package was installed. Copies of existing NumPy 1.26.4 and SciPy 1.14.1 exclude all bytecode caches; home and other temporary files are hidden, dependencies are read-only, and PID/network/mount/user namespaces isolate the numerical workers.

The implemented mechanics are a distinct small-strain linearized periodic triangular-network model. For each alive edge, extension e = n dot (u_j-u_i) + gamma*n_x*n_y. Axial energy is [r*e^2 + (1-r)*(e-q)^2]/2. Collinear bending energy is kappa*[n_perp dot (u_next-2*u_i+u_prev)]^2/2. Quasistatic equilibrium uses a sparse conjugate-gradient solve of the symmetric quadratic energy. Internal q relaxes toward frozen extension by an exponential update with assumed rate exp(10*abs(e-q)). Hold amplitude is .1 and internal duration 5; neither is a calibrated biological deformation/time. This linear geometry omits the previous nonlinear solver's finite-strain geometric stiffening and fracture. Do not present the CPU work as a reproduction of its H100 results or as a test of strain-induced nonlinear criticality.

Production: widths 12, 18 and 24; four seeds per size/setting; seven coordination targets 1.2, 1.6, 2.0, 2.4, 3.2, 4.0, 4.8; four interventions (uniform, triangle-biased hexagon flips, triangle-suppressed hexagon flips, fixed-node hub-biased edge replacements). Edge counts and directional edge counts are matched. Triangle interventions preserve the complete degree sequence. Their active bending motifs can change. Hub bias can co-change clustering and fragmentation; it is not an isolated degree-variance intervention. The finite 100*N proposal chains are controlled interventions, not demonstrated equilibrium topology ensembles. Accepted moves and achieved metrics must be reported.

Two bending coefficients (.003 and .03) and elastic versus selective-axial-relaxation r=.5 give 1,344 planned production cases. The central-force control repeats the 336 graph settings with kappa=0 and r=1. Half-time-step refinement covers 16 r=.5 cases at width12, seed73000, z3.2/4.8, both bending coefficients and all four interventions. Width24 uses new seed IDs 74000-74003; smaller sizes use 73000-73003. Settings along z share initial seed streams and are correlated. A case/time step/solver repeat is not an independent graph specimen.

The initial benchmark had eight mechanical cases on four graph settings. It passed convergence and elastic-null checks in 1.34 seconds. Production adds an independent directional finite-difference gradient check and a translational-null residual check. The first additional control launcher failed before numerical execution because the namespace wrapper was omitted; its log is preserved and the launcher was corrected. Both control runs then run sequentially on one worker, alongside production on the other, with a common deadline.

Matching G0 is implemented by the exact uniform energy-rescaling equivalence in this quasistatic model: report stress/G0, while equilibrium geometry and dimensionless internal strain-memory law are unchanged. This compensates microscopic stiffness; it is not architecture alone at fixed fibre stiffness. Unresolved and numerically nonrigid cases are excluded from matched-stiffness contrasts, with exclusion counts retained. The chosen G0>1e-6 eligibility cutoff is a declared operational gate, not a universal rigidity threshold; examine sensitivity.

The runtime supplies exp(-5) as an analytic fully relaxing homogeneous-energy reference. For equal equilibrium fraction, the derived analysis also reports the analytic null r+(1-r)*exp(-5), matching the earlier homogeneous-relaxation control convention. These are analytic nulls, not independently simulated case trajectories.

Connectivity uses component statistics and winding in the two oblique periodic lattice basis directions, not a mistaken Cartesian side-contact criterion. No arbitrary long edges or growing preferential-attachment network is modeled. Low-degree local clustering is defined as zero. All graph geometry, force-field parameters, times and stresses are dimensionless.

Software: Python 3.11.2, NumPy 1.26.4, SciPy 1.14.1. No molecular, GPU or neural-model library is needed for these numerical sweeps. Per-direction edge count is round(z_target*N/6), so total edges are exactly three times that integer and realized z can differ slightly from its target. No forced line-cut correction is used in this new generator. The prior original network builder is not modified by this study.
