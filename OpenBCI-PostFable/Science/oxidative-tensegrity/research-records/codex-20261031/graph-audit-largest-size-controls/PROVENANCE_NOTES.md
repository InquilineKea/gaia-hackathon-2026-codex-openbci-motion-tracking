# Provenance and interpretation

The previous campaign's eight-case preliminary benchmark source was not separately retained; its exact production and later rate-control source were retained. This follow-up derives model.py from that exact rate-control source, preserving the graph function identically (AST comparison recorded). Changes to mechanics only log the uncapped rate argument/cap activations and extend a bounded runtime deadline. Separate audit/control directories preserve each worker's own isolation and gradient self-test records. Exact execution sources, transmitted hashes and remote result hashes are retained.

Graph reconstruction uses the original generator, original seed identifiers, and existing NumPy1.26.4. It must match each of336 prior mask hashes. Reconstructed active-edge indices, degrees and node component labels are retained. The graph audit is new measurement of the same finite specimens, not an independent simulation ensemble or additional replication. Mean-field or thermodynamic interpretations are not implied by a degree histogram. Giant-component ties use the first root visited in ascending node order. Directional winding flags may differ from rank-two winding within one component; neither metric establishes rigidity or biconnectivity.

The same dimensionless linearized axial/collinear-bending strain-memory model is used for384 largest-size mechanical controls. Relaxation times, energies and stresses lack biological calibration. Constant beta0 and zero-bending cases are designated controls. The predeclared refinement criterion concerns the retained-stress observable, not the whole trajectory, displacement null modes, molecular validity or continuum correctness. Failed/ineligible states must remain distinguished from converged positive-stiffness matched pairs.

The shared GCP host is retained running. No new instance, new numerical package, GPU workload, chemistry calculation or new graph-seed replication is part of this follow-up. Installed package RECORD checks and dependency file hashes are not independent vendor attestation. Gemini model outputs are source-checked leads, not external literature verification or experimental validation. Only final response text and token metadata are retained, never model thinking text or credentials.
