# Parameter/source attribution

The original task driver, preparation and analysis adapters are Codex-generated research code. They do not replace the upstream sources or their licenses.

Glucosepane topology/residue data and the starting fibril coordinates come from Giannetti and colleagues, DOI 10.1093/bioinformatics/btag409, and https://github.com/gggguido/AGEs-ColBuilder at commit 4e51b2bb6ab747ba4c8743b3f676a448f8b26d43. Retain their source headers and attribution. The source set extends ColBuilder/Amber data; ColBuilder license information is included. No blanket new ownership or relicensing of third-party parameter data is asserted.

The DITY patch/parameter data come from Graham and colleagues, DOI 10.1016/j.xcrp.2026.103319, via Zenodo record 16865891 (archive version 1.0.1), whose metadata identifies CC-BY-4.0: https://creativecommons.org/licenses/by/4.0/ . The modified CHARMM XML is derived from the exact locked OpenMM wheel plus these data; retained upstream references and any included license notice remain applicable. The derived XML is not represented as an official new OpenMM or CHARMM release.

The package contains no software wheels, container image, proprietary checkpoint or executable from the authors' repositories. Existing software is identified by version and hash for reviewed reproduction.
